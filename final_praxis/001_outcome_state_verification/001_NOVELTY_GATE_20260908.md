# Final Praxis 001 — Novelty Gate

Date: 2026-09-08
Status: **PASS WITH RESCOPE**

## Working title

**Independent Outcome-State Verification for Agent Task Completion Under Evaluator Disagreement**

## Decision

The broad claim "use deterministic final-state verification for agent task completion" is **not novel enough**. Prior work already includes state-based evaluation in τ-bench and AppWorld, deterministic measurement of planted reward-hacking opportunities in Hack-Verifiable Environments, and proxy state-based evaluation for tool-using agents.

Final Praxis 001 remains viable only under a narrower contribution:

> **Measure when judge-based agent-success evaluation accepts task completion that an independent machine-checkable postcondition verifier rejects, while preserving legitimate alternate solution paths and explicitly measuring collateral state changes.**

The experiment is therefore not a new benchmark for reward hacking and not a new claim that final-state evaluation is useful. It is an evaluation-integrity study of **judge/postcondition disagreement** under controlled task-completion failure modes.

## Exact novelty sentence

**Final Praxis 001 tests whether machine-checkable environmental postconditions reduce false-success acceptance relative to judge-based evaluation across controlled incomplete, falsely claimed, collateral-damage, and alternate-valid-path completion states, with both security and legitimate-task utility preregistered.**

If this sentence cannot remain true after the final literature audit, stop the experiment.

## Novelty kill criteria

Classify the experiment as **NOVELTY FAIL** before any model run if a verified prior paper already performs all of the following together:

1. compares LLM/agent judge success labels directly against independent machine-checkable final-state truth;
2. includes controlled false/incomplete completion states rather than only ordinary success/failure;
3. permits multiple legitimate solution paths rather than matching one canonical trajectory;
4. measures collateral/unintended state change;
5. reports false-success acceptance and legitimate-success preservation as co-primary outcomes.

## Scope boundary

Final Praxis 001 does **not** claim:

- that final-state evaluation is new;
- that deterministic evaluation is always preferable to LLM evaluation;
- that it solves reward hacking generally;
- that all real-world tasks admit complete postconditions;
- that a verifier cannot itself be misspecified;
- that controlled false-success fixtures represent malicious intent by the model.

## Gate 0 result

**PASS WITH RESCOPE.** Proceed to preregistration and fixture design under the narrower evaluator-disagreement formulation.
