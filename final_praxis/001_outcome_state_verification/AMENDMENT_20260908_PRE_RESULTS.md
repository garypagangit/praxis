## Controlled stress versus natural behavior

The original documents simultaneously request natural agent outcomes and exactly balanced outcome-state labels. Natural execution cannot guarantee a fixed number of successful or failed states. The primary experiment is therefore explicitly a **controlled evaluator-stress experiment**, as allowed by the draft's controlled-state hypothesis. It is not an estimate of natural agent failure prevalence.

For each case, Qwen proposes real assignments through an inert JSON interface. The harness executes those assignments, retaining the unmodified natural state and action-output text as a separate descriptive corpus. Independently of agent quality, a controlled state projection realizes the preallocated condition, records the intervention and authoritative state, and reports actual resulting values for fields named in the agent's proposed assignments. Qwen then generates an honest completion assessment from those observations. Mistral judges that same public record plus the real completion text. No model decision is generated by a fixture, oracle, heuristic, or desired result. Natural state outcomes and imposed state outcomes are never pooled.

Condition names are allocation labels, not guaranteed claim contents: a false-success target may yield a correct refusal or failure admission. Such cases remain in the denominator. The term FSAR denotes judge acceptance of imposed invalid states, including units where the agent admits failure. A supplementary analysis can condition on genuine success claims but cannot replace the frozen primary denominator.

The full-state verifier has more information than the primary judge. Its accuracy on labels defined by these same predicates is structural, not an empirical proof of verifier superiority. The empirical quantity is learned-judge disagreement under an explicit observation regime. A preselected diagnostic gives Mistral the complete final state on 40 cases (first clean and first collateral case per template) to assess this limitation. This diagnostic cannot rescue a failed primary gate.

## Task and verifier repairs before outputs

Scientific instances vary symbolic identifiers deterministically so the 20 repeated task structures are not byte-identical model inputs. Replicates remain clustered by template; a template-cluster bootstrap supplements the frozen within-template paired bootstrap.

The old alternate fixture added a metadata tag without changing a solution path. Scientific alternate states instead reverse the legal assignment order and, for set-valued allowlists, reverse element order. Representative multi-field tasks in every family have distinct action order; one-field tasks do not offer a substantively different order. Single-predicate tasks also make partial and incomplete failures coincide. Both limitations are reported rather than relabeled away.

The verifier now accepts legitimate set order permutations, rejects bool/integer equality masquerading as schema correctness, and returns failure for missing/malformed fields. Scientific instances explicitly protect every initial field not named as a goal, completing the stated preserve-unrelated-state requirement. Original goal and invariant values remain unchanged except for deterministic symbolic-ID substitution. Each scientific predicate and invariant receives an independent negative test in addition to the old fixture suite.

A maximum of two infrastructure retries may be used by the shared adapter; request and failure metadata must remain recorded. No response repair inference is allowed. Malformed decisions count as rejection; raw text is preserved. A 16-case infrastructure pilot precedes discovery. Model identity or parser substitutions require another dated amendment before affected outputs are used.

Replication is not automatically authorized under the discovery protocol because the reserved replication agent is the discovery judge. A separate independently frozen judge or task-domain replication design is required before claiming cross-model robustness.

This amendment does not promise positive results, broad novelty, or a publication-ready conclusion before the experiment and independent audit finish.
