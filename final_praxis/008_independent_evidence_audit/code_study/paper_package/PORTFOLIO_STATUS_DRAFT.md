## 008 contribution and citation boundaries

The targeted primary-source review already found very close prior work. PBRC section 9.2 explicitly describes valid-but-selectively-acquired evidence and query-policy controls. When Helping Hurts already studies critic corruption and executable evidence gating. DiffTGen and Poracle cover differential patch testing/preservation; CodeMonkeys and S* use test-based candidate discrimination; TDAD covers code-aware test selection. Therefore the known threat, extra test execution, an ordinary veto, or a simple edit-aware sampling score cannot alone be sold as novel. [Closest-prior matrix with primary links](../literature/CLOSE_PRIOR_MATRIX.md).

The defensible prospective target is a **controlled empirical characterization** of whether selected truthful test witnesses change harmful-revision acceptance while retaining useful repairs, plus a measured process/policy extension if it improves on frozen matched-budget baselines. The final study must distinguish reviewer behavior from the logical effect of vetoing authenticated failures. A uniform component's finite-pool bound is a standard sampling fact, not a new theorem. A static edit heuristic is not a reproduction of coverage/differential testing or evidence of superiority over that literature.

HumanEvalFix native bugs are inserted bugs, not native histories of model mistakes. Deliberate red-team corruption is not naturally occurring model error. HumanEvalPlus reserved tests are hidden from experimental actors, not guaranteed unseen in model pretraining. Passing finite tests is a reserved-suite outcome, not proof of semantic correctness. Neither translations nor repeated seeds create new independent tasks. These restrictions are part of the study design, not caveats to add only after a disappointing result.

Citation verification was a targeted primary-source review, not a systematic-review or novelty certification. The Rothermel–Harrold 1997 publisher DOI was identified, but detailed theorem comparison from the publisher text remains incomplete; the matrix explicitly records that limit. Do not state that every linked full text or every adjacent testing literature was exhaustively reviewed.
