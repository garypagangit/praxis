# Independent adversarial validation

These synthetic controls are specified independently of the repaired scorer implementation. They contain no upstream data, reference answers, or released model outputs. Expected outcomes are chosen from the stated contracts and are not generated by calling the scorer.

`controls.json` separates answer agreement from table restoration. Numeric tolerance is an explicit part of the relevant fixture; the default is exact finite numeric equality. Booleans are distinct from numbers. Strings remain strings, including identifier codes and textual JSON. Ordered lists preserve order and multiplicity; multiset lists disregard order but preserve multiplicity; set-valued tasks require an explicit set contract. Nested mappings compare both keys and values. Nonfinite references are invalid measurement inputs, not model failures. Missing outputs and execution errors are distinct recorded failures. A genuine JSON null is not a missing output.

The table fixtures specify a unique record key and an exact column contract. They are deliberately a stricter table-restoration measure than purpose-answer agreement. Reordered records with unchanged keys and values pass. Added/deleted records, changed nulls, and missing/extra columns fail. Missing, null, or duplicate record keys make correspondence ambiguous and must not produce a successful comparison. A scorer that deliberately does not implement table restoration should record these fixtures as not implemented; that does not prevent reporting narrowly defined answer agreement.

Do not quietly narrow the fixture set until the implementation passes. Any unsupported contract must be named in the result and excluded from scientific claims that require it.

## Acceptance criteria and interpretation

1. All supported synthetic controls produce the manually specified decision; invalid-reference controls are counted separately from valid-reference failures. Report coverage for unimplemented controls. References containing nested NaN must never count as successfully qualified by identity.
2. Explicitly map every included task to a purpose, executable query, reference, answer contract, and provenance. An integer-safe scorer repairs a software defect but does not repair a count question whose gold is a list, an unspecified truncated mean, or inconsistent prompt wording.
3. A full reference-self-test and a deliberately corrupted-answer test establish narrow scorer properties. They do not validate the underlying gold or establish capability. Task success requires a separately justified purpose/query contract and checks against the actual records or an independent trustworthy answer.
4. Replaying saved answer files measures agreement for those released artifacts. It does not by itself establish that a model generated a corresponding cleaned table. Separate available output tables, raw-table fallback, missing generation, execution error, and missing answer. Keep their denominators visible.
5. Freeze evaluation-contract choices before examining model rankings. Preserve original and amended scores separately. If ambiguities remain, publish strict lower/upper coverage bounds or per-stratum results; do not silently remove hard tasks and promote the resulting accuracy.
6. Do not infer that useful correction behavior exists solely from high gold agreement. Compare the same query on raw tables; measure correction and harm on initially incorrect/correct cases. Repeated task views of the same underlying source table must share splits.
7. A future intervention must not inspect held-out gold, expected cleaned cells, or evaluation outcomes at runtime. Evaluator-only artifacts must be separated from specialist/controller inputs. Public artifacts can be contaminated by publication or training, so qualification establishes a public benchmark baseline rather than independent generalization.

Until purpose contracts and generation provenance are qualified, the defensible statement is **repaired typed agreement on released answers**, not purpose success or a capable specialist baseline. This work is a measurement prerequisite, not a novel Praxis contribution by itself.
