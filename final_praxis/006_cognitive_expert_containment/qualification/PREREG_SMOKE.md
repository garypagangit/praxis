# Final Praxis006: public checkpoint and routing qualification

Frozen12September2026 before loading weights or generating model answers. This is a technical/capability feasibility gate for option3, not a test of a new containment method.

**Main research question:** can a conditional routing intervention contain an unreliable cognitive expert while retaining its useful contribution to valid corrections? [MiCRo](https://arxiv.org/html/2506.13331v3) supplies learned logic, social, world and language experts, public checkpoints and expert-ablation experiments. Existing ablation/routing repair is prior art; neither removing an expert nor this smoke test is claimed novel. A future defensible contribution must improve selective containment beyond permanent removal and ordinary verification, with specialist-task non-regression.

**Qualification RQ:** can the public smallest MiCRo checkpoint load without missing learned tensors and produce finite, deterministic outputs with observable routing, under baseline and its published social-expert ablation?

**H-Q1:** the pinned checkpoint/source load with matching architecture and finite logits; repeating a baseline forward pass is stable within numerical tolerance. Eager and SDPA attention agree on a fixed input within maximum absolute logit difference1e-3 and the same top token. Failure is implementation/portability evidence, not a scientific null.

**H-Q2:** the published ablation API excludes the social expert from selected routes, changes some outputs or routing, and leaves enough task capability to support a later selective-containment study. The null is no detectable routing/output change or an uninformative capability floor. A positive result would establish manipulation feasibility only.
