# Final Praxis 002 — pre-result implementation amendment

Date: 2026-09-08. Written before any real model output for this experiment was observed.

The earlier design freezes four arms, six error families, 480 workflow runs, 144 minimum fixtures and promotion thresholds. Those requirements are preserved. The following previously unspecified details are resolved prospectively to make the experiment executable and auditable.

1. The 120 matched conditions are 60 base scenarios with one clean and one injected version each. Ten base scenarios belong to each error family. Each condition is executed under all four arms. The case manifest is model-independent and frozen before inference.
2. All three stages use the real Qwen/Qwen2.5-7B-Instruct model, revision `a09a35458c702b33eeacc393d103063234e8bc28`, BF16 without quantization, greedy decoding, maximum 256 new tokens and seed 20260908. There are eight concurrent workflow workers. The same model occupies different logical roles; this does not establish heterogeneous-agent generality.
3. The controlled corruption is applied after real triage generation and before the first optional handoff gate. The original triage output is preserved. Clean conditions retain the actual unmodified triage output, including natural mistakes. The injection overwrites/appends only its prespecified field and does not manufacture downstream model responses.
4. Every agent receives the original machine-readable evidence and policy. Agents can independently repair prior mistakes. Case IDs, injection family, condition label and hidden expected outcomes are not exposed in prompts. Existing model mistakes are retained, not repaired by the harness.
5. Propagation depth is the count of consecutive invalid downstream model outputs after the injected triage handoff: zero when the first gate contains the handoff or the investigation repairs it, one when investigation remains invalid and response repairs it, two when both remain invalid. It excludes the known injected stage. Per-stage reasons are preserved to distinguish survival, correction, transformation and newly introduced errors. This is an operational output-persistence metric, not a claim of semantic causal identification for every model-generated error.
6. Handoff gates check schema, evidence, claims, identifiers, provenance, policy and disposition. Final-action-only gates check symbolic action/target validity, not upstream metadata. A blocked workflow ends in review and fails clean utility. REVIEW is an abstention. A missing/unparseable final action never executes and fails utility. A parsed but policy-invalid action executes only in the symbolic registry and counts as invalid. Even `no_action` requires the correct case target to count as successful completion.
7. Paired 95% intervals use 20,000 bootstrap resamples, stratified over the six error families with ten paired base scenarios per family, seed 20260908. The primary interval is A0 minus A3 CER; the gate-placement depth interval is A1 minus A2. No multiplicity-adjusted broad claim is made; all mandatory gates must pass. Zero bootstrap variance is reported honestly and is not evidence beyond the frozen cases.
8. An infrastructure pilot uses B001 and B011, both conditions and all arms (16 workflows). Its raw outputs are kept separate and never substituted for the 480 discovery records. No scientific thresholds, scenarios or prompts may be tuned using its directional outcomes. The complete frozen discovery is run even when the phenomenon is absent, so a negative determination has full denominators.
9. At most two infrastructure retries per workflow are allowed, with immutable attempt directories and unchanged prompts/settings. Semantic mistakes, refusal and malformed JSON do not receive retries. Completed records are never overwritten. Exhausted infrastructure failures leave the experiment incomplete/Protocol Invalid; they are not excluded from the denominator.
10. New 2026 literature confirms that generic cascade tracking and failure localization already exist. The claim is restricted to the paired deterministic gate-placement experiment with machine-checkable symbolic security outcomes. The refreshed source table is `NOVELTY_REVIEW.md`.

The final-action gate prevents invalid symbolic actions by construction. That expected fact alone cannot be presented as scientific novelty. Positive promotion still requires the frozen ungated phenomenon, clean utility, downstream propagation and gate-placement gates. Fixture outcomes are never scientific evidence.
