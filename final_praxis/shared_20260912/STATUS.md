Existing Final Praxis001–003 retain their historical numbering; these are new branches004–007. Each branch contains its own protocol, code and result/status documents.

**The research questions and hypotheses.**

- **004:** Can a solver retain a correct repair under an unreliable specialist while accepting useful feedback? Hypotheses require initially correct and wrong repairs, admitted misleading tests, and better preservation without lost recovery. The initial-capability gate failed. [Protocol](https://github.com/garypagangit/praxis/blob/Final-Praxis-004-Specialist-Revision/final_praxis/004_specialist_revision/PREREGISTRATION.md).
- **005:** Does an extended-refusal defense persist through benign teacher-generated adaptation, and does replay help preserve it while retaining utility? The current same-size hard-label adaptation is not a compression or extraction-attack result. A positive retention result alone would not establish novelty. [Protocol](https://github.com/garypagangit/praxis/blob/Final-Praxis-005-Defense-Distillation/final_praxis/005_defense_distillation/PREREGISTRATION.md) and [novelty correction](https://github.com/garypagangit/praxis/blob/Final-Praxis-005-Defense-Distillation/final_praxis/005_defense_distillation/NOVELTY_AMENDMENT.md).
- **006:** Can conditional routing contain an unreliable expert while preserving useful corrections and specialist performance? The first hypotheses establish public-checkpoint capability and observable intervention. A later selective method must beat existing permanent ablation and ordinary verification. [Protocol](https://github.com/garypagangit/praxis/blob/Final-Praxis-006-Cognitive-Expert-Containment/final_praxis/006_cognitive_expert_containment/PREREGISTRATION.md).
- **007:** From an identical initial answer, do extra solo review and false peer advice cause harmful changes while valid evidence still supports recovery? That behavioral setting is measurable; a future mathematical/process contribution must improve selective updating on untouched examples and survive an overlap review. [Protocol and results](https://github.com/garypagangit/praxis/tree/Final-Praxis-007-Overthinking-Revision/final_praxis/007_overthinking_revision).
