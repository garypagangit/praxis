# 007 stage 2: does counterfactual label instability add decision value?

Frozen before any stage-two inference, 12 September 2026. This is a bounded comparative falsification pilot, not a confirmed novel method or a sufficiently powered publication study. Stage-one outputs informed this question; they cannot provide confirmatory evidence. See NOVELTY.md for the current primary-source overlap review.

## Literature and research question

[SRU](https://arxiv.org/html/2608.26511v1) identifies the tension between resisting unsupported pressure and retaining rational updates, and releases EX-FEVER data. [SWAY](https://arxiv.org/html/2604.02423v1) already proposes imagined counterfactual prompting and measures evidence responsiveness. [Self-Blinding](https://arxiv.org/html/2601.14553v1) already calls actual blinded replicas. [Resist and Update v2](https://arxiv.org/html/2607.12985v2) uses an incentive-neutral reference and activation intervention. Counterfactual invariance, blinded verification, and robust minimum margins are therefore NOT our novelty claims.

RQ: At three useful calls per decision, does disagreement induced by explicitly unsupported alternative peer labels identify harmful candidate updates better than ordinary repeated verification, while preserving evidence-supported recovery? A secondary question asks whether this remains useful when a supplied passage belongs to a different question. The candidate contribution is the incremental decision value of an intervention-specific instability signal, if demonstrated. Generic resistance alone does not qualify.

H1: On untouched test questions, the finite-label veto reduces loss of initially correct answers by at least 5 percentage points compared with both repeated-verification majority and repeated-verification unanimity, while losing no more than 5 percentage points of their recovery of validly wrong initial answers in the reference-evidence condition. Both model families must meet the observed-direction criteria before further substantial investment. These are screening thresholds, not declarations of statistical significance.

H2: Among changed, valid evidence-only candidates, label instability is associated with candidate error beyond repeated-verification instability. Report the complete cross-tabulation by the two binary instability indicators, with counts and error rates. Do not fit an underpowered multivariable predictor or claim calibration/certification. H2 is exploratory; fewer than 20 changed candidates with outcome variation makes it inconclusive.

## Process and mathematical rule

One initial answer y0 is generated per question at temperature 0, maximum 64 output tokens. Its exact response is frozen and reused as the assistant turn in every check. The seven checks per evidence condition receive identical claim, initial response, evidence and final-format instructions. Three evidence-only checks B0,B1,B2 have byte-identical messages, distinct request IDs and temperature 0.3. Two intervention checks T,F add the same statement except the asserted label TRUE or FALSE. Neither assertion is chosen using gold. All peer statements explicitly lack supporting information. No check sees another check's response.

Let b be B0's valid label. Candidate gate: output b iff B0,T,F are valid and identical; otherwise KEEP y0. This is an external deterministic acceptance rule, not a learned model modification. It can only veto B0 and cannot improve B0's recovery of a wrong y0; any value must come from a better harm/recovery tradeoff. Repeated-verification unanimity uses B0,B1,B2 with the identical veto. Repeated-verification majority requires all three valid and uses their binary majority; otherwise KEEP. B0 alone, KEEP, and ungated T/F are diagnostic controls. A one-assertion veto using B0 and T is a two-call ablation. Invalid initial answers remain invalid under KEEP, are excluded from conditional C/W denominators, and count as failures in overall accuracy.

Two additional checks apply a zero-shot, abbreviated SWAY-inspired five-step instruction to T and F. They are a transparent prompt adaptation, NOT a reproduction of SWAY's published ten-example prompt or its numerical results, and are one-call lower-cost diagnostics. The matched-cost primary comparators are the three-call repeated checks. Every check uses temperature 0.3 and maximum 256 output tokens. Actual tokens, latency, requests and estimated costs are reported; equal ceilings are not equal consumed tokens. Sampling is stochastic and managed model weights cannot be hash-pinned.

Models: qwen.qwen3-coder-next and mistral.devstral-2-123b through AWS Bedrock in us-east-1. All outputs use TRUE/FALSE. The preregistered parser accepts exactly one terminal `FINAL: TRUE` or `FINAL: FALSE`, with the previously tested single balanced Markdown wrapper or whole JSON-string normalization; it rejects ambiguous, missing and truncated responses. Record both raw and normalized text, finish reason, token counts and validity. No LLM extraction, verbal-confidence substitution, adaptive retries to get a label, or output execution.

## Analysis and investment rules

Report calibration and test separately, per model and evidence condition. For ungated peer/SWAY diagnostics select the wrong-label branch only during scoring (gold never enters generation), and also report both literal-label branches. Primary candidate/comparator decisions never use gold. Count initial C/W/invalid; C-to-W, C-to-invalid, W-to-C; overall accuracy; update coverage; invalid cells; harmful accepted-update risk; and invariant-but-wrong accepted updates. Primary harm includes invalid final answers among initially correct cases, so format failures cannot look protective. Count questions, not repeated arms, as independent units.

Provide paired question bootstrap 95% intervals with 2,000 replicates and fixed seed 70072, keeping all conditions together within a question. Report both pooled three-condition harm and each stratum, reference recovery separately, and H1 against each matched-cost comparator; do not choose whichever comparator is easier. Intervals are exploratory and multiplicity is not controlled. If counts are inadequate or intervals remain wide, report inconclusive, not efficacy. A strict positive-investment signal additionally requires harm-difference interval upper bounds below zero and reference-recovery difference lower bounds above -0.05 against both comparators in both models. Otherwise retain or reject based on explicitly descriptive evidence only, without a publication claim.

For descriptive coverage control, determine comparator thinning probabilities on calibration only: min(1, candidate_update_rate/comparator_update_rate) per model/condition. Apply to test updates using SHA256 of fixed seed/model/condition/question/comparator, never test correctness. Report resulting achieved coverage and paired metrics; do not call the realized coverages exactly matched. Thinning cannot increase a comparator's rate if the candidate updates more often. Report raw full-coverage comparisons alongside this sensitivity.

Reject the added mechanism if it is equivalent to a cheaper check, loses too much legitimate recovery, produces gains only via formatting or KEEP, or does not outperform repeated verification. Consistent wrong outputs disprove any claim that finite invariance certifies truth. Small-model white-box work in branch006 is a companion synthetic-fault study, not a mechanistic explanation of hosted-model behavior.

### Frozen interpretation clarifications before inference

The temperature-0.3 rule is a finite sampled label audit, not an invariant envelope or correctness certificate. A single draw per asserted label mixes sampling variation with the assertion intervention; the matched-policy comparison estimates incremental decision value, not a proof that a particular item's disagreement is caused by its label. H2 uses valid initial answers and valid changed B0 candidates only.

Invalid checker replies can cause KEEP even when the final output is valid. Therefore report invalid-veto counts and additionally require at least 95% of evaluated question-condition rows to have a valid initial answer plus all five core check labels. A strict positive-investment flag also requires the same harm/recovery confidence-interval criteria on that joint-valid subset. This is a post-response diagnostic subset, not an unbiased replacement for the full-cohort primary comparison. Both full and subset results must be shown; neither a formatting failure nor stable wrong agreement certifies resistance. The shared adapter defaults remain greedy for older runs; this runner explicitly opts into the frozen allowed temperatures (0,0.3).
