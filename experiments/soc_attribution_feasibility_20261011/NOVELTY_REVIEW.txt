TARGETED NOVELTY REVIEW — OCTOBER 11, 2026

Current decision: a plausible applied evaluation question remains; no new detector
or established novel contribution has emerged yet. A fair-comparison protocol and
data-readiness demonstration are useful engineering progress, not novelty proof.

Search scope
Primary paper/release pages and official documentation; terms combining human,
script, AI, terminal, attribution, matched data, hybrid and SOC telemetry. Inspected
TRACE full HTML, OHAI report landing page, Honey institutional abstract/release,
Lyptus repository, relevant public dataset cards, and adjacent-paper abstracts.
No systematic review, citation-complete search or firstness claim. Differences
below are scoped to inspected material; do not assert omissions from unavailable
full methods. Existing portfolio PX-117–125 already tests several of these ideas.

Closest work and claim implications

TRACE — https://arxiv.org/html/2605.01186v1
Passive terminal fingerprints with TF-IDF/linear classification, AI-family labels,
scaffold transfer and active forensic intervention. Fingerprinting and unseen-
scaffold evaluation are not new here. Our candidate distinction is incremental
information value for runtime-AI participation against H/S/M controls in a defined
defender view. This is a proposed difference in evaluation, not a proved gap.

OHAI — https://www.sei.cmu.edu/library/observational-humanai-ohai-a-defender-attribution-framework-for-distinguishing-human-vs-ai-threats/
An attribution framework and observable-indicator guidance spanning human through
autonomous activity. A checklist, uncertainty labels or AI-origin report alone
would overlap. A controlled comparison against a fixed checklist and measurable
decision benefit could add evidence; no such benefit is measured here.

Honey — https://orbit.dtu.dk/en/publications/honey-for-the-agent-cyber-deception-and-behavioral-fingerprinting/
AI command-selection fingerprints across model/prompt/environment conditions and
environmental influence. Cross-environment fingerprints and cue responsiveness
already exist. Additional outputs must demonstrate incremental information rather
than merely identifying the environment. Institutional abstract and release were
inspected; full publisher text is embargoed there, so no full-method omission claim.

Human, Script or AI? — https://markuswalker.com/assets/docs/Markus_Walker_AI_Driven_Attacks_White_Paper_v5
Independent advisory paper, evidence cut September 23, 2026. Directly overlaps the
human/script/AI SOC framing and cautions about ambiguous behavior. Treat as relevant
prior guidance, not peer-reviewed validation or a released matched benchmark.
The title and concept of distinguishing scripts from AI cannot be claimed new.

ALTEDA — https://www.sciencedirect.com/science/article/pii/S0306457326001597
Publisher-indexed abstract describes log-based compromise detection/attribution
within a red-teamed multi-agent medical system. Log fusion and attribution without
prompt inspection have prior art. Different target: compromise and responsible
agents/interactions, not human/script/AI origin in a suspicious shell session.
Direct page open failed; inspected publisher search text only. Full methods need
review before any detailed gap claim involving this paper.

Cross-Agent Campaign Attribution — https://arxiv.org/abs/2607.18826
Proxy-side campaign linking across LLM-agent sessions using observable tool-use,
timing and prompt residue. Abstract describes controlled matching/leakage checks.
Matched attribution evaluation is not a new general method. Different target and
observation boundary; do not call our session-origin classifier APT campaign linking.

Bounded Reasoning — https://arxiv.org/abs/2610.04878
Recent human-versus-automated defender comparison in a cyber-defense game, including
adaptation after outcomes. This is adjacent evidence that feedback/behavior matters,
not proof output-conditioned attacker-origin classification works. Abstract read.

Microsoft Sysmon documentation — https://learn.microsoft.com/en-us/sysinternals/downloads/sysmon
Defines process and other telemetry events. This is an observation reference, not
attribution prior art: do not treat process-create logs as full terminal recordings
with returned output. Our contract requires an instrumented managed session.

Our own prior results
PX-125 already compared behavior with response-conditioned features and did not
improve the comparator. Repeating the same exposed-data experiment is not a new
contribution. PX-124 already showed weak transfer/coverage. New work must supply
better-qualified measurements, a defensible comparison or a useful new finding.

Candidate questions ranked
1. Incremental value of outputs/timing after ordinary-automation and source controls.
   Plausible; no benefit demonstrated. Best next scientific question if comparable
   data can be obtained. Keep genuine scripts and hybrid prefixes explicit.
2. Which telemetry permits defensible origin assessment, and where does it fail?
   Plausible measurement/reliability study using public data. Must add quantified,
   reproducible evidence beyond established warnings about confounding.
3. Does a supported evidence report reduce analyst error or time versus a checklist?
   Plausible application; depends on meaningful evidence and actual human study.
4. New transformer, new dashboard, or generic fingerprint score.
   No novelty established by architecture/interface choice alone; low priority.

What would count as fruitful
A modest transfer-stable gain at a fixed review/error budget, demonstrated with
qualified data and simple controls, is enough to justify continuation. A rigorous
negative boundary or data/measurement artifact can also contribute if it answers
an unresolved practical question. Neither the metadata shortcut nor an identical-
trace fixture is claimed as a novel scientific discovery.
