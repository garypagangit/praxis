PUBLISHED DATA FIRST — OCTOBER 11, 2026

Answer: you do not have to create a large new dataset. Published data can support
development, bounded attribution evaluation and a reliability/measurement Praxis.
For the full fair four-origin comparison, we have not yet verified a published
release with all required labels and comparable observations. A small supplement,
or a narrower claim using existing data, is preferable to automatic new collection.
No participants are arranged. That blocks new genuine H/M collection and an actual
analyst-benefit study; it does not block all useful research.

Sources and decisions (do not merge independent release counts)

1. Lyptus Offensive Cyber Task Horizons — best existing paired-task starting point.
   https://github.com/lyptus-research/cyber-task-horizons-data
   Human and AI terminal/task records. Today's byte/schema audit rechecks 90 human
   and three selected AI archives: 87 finalized human samples and 222 AI samples.
   Native human terminal and AI tool recording differ. Shared >=3-submission
   development slice: 25 H, 42 A, 24 tasks, five human groups. At >=5: 10 H/15 A,
   ten tasks, three human groups. No independently labeled script/hybrid arms in
   inspected slice. CC-BY-4.0 per release. Suitable for development/reliability;
   recorder equivalence and origin-specific claims need qualification. Already
   exposed local cases are not fresh confirmation. Not the entire AI corpus.

2. KYPO/cyber-training human shell commands — useful external human stress source.
   https://doi.org/10.1016/j.dib.2021.107398
   Published description: 13,446 commands, 175 participants, 27 training sessions;
   command/arguments and metadata such as time, directory and host. Do not infer
   full returned output from that description. Older human training data can test
   false flags, but tasks, tooling and date differ from AI collections. Prior
   portfolio KYPO tests already used a selected subset; not all release rows are
   automatically new or independent. Publication search text inspected; publisher
   page open failed this turn. Verify exact release/license/files before new use.

3. Honey for the Agent — useful AI-only environment-shift source.
   https://zenodo.org/records/20818246
   Released LLM shell interactions across five environments; about 16,200 files in
   release description, not an independent-human sample. CC-BY-4.0, earlier local
   download/hash qualification retained. No matched H/S/M arm. Use for conditional
   family/logging study or positive stress testing, not proof of binary specificity.

4. TRACE — relevant baseline, complete dataset access still unverified here.
   https://arxiv.org/html/2605.01186v1
   https://anonymous.4open.science/r/TRACE-A66F
   Rechecked paper scope. Prior direct artifact API returned 401; this turn did
   not retrieve a full session release. Do not equate a paper or working landing
   page with usable matched data. Family identification among AI agents is not
   H/S/A/M identification. A method can be adapted without claiming exact reproduction.

5. HCAST — reuse tasks; human time estimates are not human command transcripts.
   https://github.com/METR/hcast-public
   Public repository explicitly describes a subset of task source code and MIT
   code license. It does not by itself verify downloadable matched human session
   traces. Potential supplemental collection scaffold; respect benchmark solution
   handling. We did not download solutions or run its tasks.

6. Terminal-Bench / TUA-Bench — task environments, not a verified four-origin corpus.
   https://www.tbench.ai/news/announcement
   https://github.com/facebookresearch/TUA-Bench
   Human-authored/verified tasks or solutions do not mean human-operated action
   logs. Candidate reusable environments if future collection is needed; current
   descriptions do not supply the missing matched negative controls.

7. Shell Attack Evolution — realistic command/response stress, origin unknown.
   https://github.com/zyw-286/shell-attack-evolution-dataset
   Released Cowrie request/response data for 2021–2022 and 2024. Dataset CC-BY-4.0,
   code MIT per repository. The inspected description labels attack techniques,
   not verified AI/human/script origin. Never label all historical honeypot traffic
   human, or all repetitive activity scripted. Useful unlabeled deployment-shift
   and parser stress data; it cannot measure origin accuracy without ground truth.

8. GOAT GATC public coding-session sample — adjacent AI/human-interaction source.
   https://huggingface.co/datasets/GOAT-AI/gatcv6
   Data card reports a 1,189-session public sample, Apache-2.0 for the sample;
   full corpus licensed separately. v2 dated October 11 changes masking and adds
   session_kind. Use current revised data only if later acquired. User messages
   plus agent replies do not certify a hybrid terminal action-control label, and
   coding is a different domain. Useful candidate for extraction/metadata checks;
   no matched S/H baseline established by the inspected card. No rows downloaded.

9. Agent trajectory attribution — different attribution target.
   https://github.com/chenjing-2024/agent-trajectory-attribution
   Initial release describes 1,351 agent trajectories with behavioral attribution
   annotations from AgentDojo/Agent3Sigma. Explaining an agent's task-aligned or
   unsafe action is not identifying an unknown operator as human/script/AI.
   It does not fill our four-arm gap. README inspected, no raw commands executed.

10. KaliBench — query-to-command examples, not operator sessions.
   https://risys-lab.github.io/KaliBench/
   Useful tool-invocation benchmark. Verified query/command pairs do not supply
   matched human and AI interactive traces with runtime-origin ground truth.

11. Commercial expert-session collections — access/labels unqualified.
   https://aliasrobotics.com/datasets.php
   Provider describes expert and other streams. A large marketing count is not
   an accessible licensed four-arm release. No purchase, contact or access claim.

12. Palisade CTF interaction data — prior inspected artifact is platform events.
   https://github.com/PalisadeResearch/ai-vs-humans-ctf-report
   Prior sample contains competition interactions, not the needed shell command
   and returned-output observations. Retain prior bounded qualification; no new
   full artifact search or download this turn.

Recommended choice
Use Lyptus as the public-data development core, KYPO as a separate human stress
check and Honey as a separate AI stress check. Use unknown-origin honeypot logs
only for applicability/coverage, not accuracy. Do not concatenate these into a
clean-looking origin classifier and call it matched validation.

Two viable research routes
A. Published-data-only: audit information availability and failure under source,
   task, prefix and representation changes; test a bounded improvement if comparable
   observations and untouched evaluation units can be qualified. No recruitment
   required. The paper's claim must remain within those populations and labels.
B. Public data plus targeted supplement: add only missing scripted/hybrid/recording
   conditions in reused lab tasks. New human involvement is required only where
   existing human records cannot answer the chosen comparison; actual analyst
   benefit additionally needs analyst participants.

Limits of this search
This is a targeted release/method review, not proof no suitable dataset exists.
Only the local Lyptus archive subset was freshly byte/schema audited. New options
above are release-description checks unless explicitly stated otherwise. A match
in a search result is not data qualification. Full access, labels, licensing and
measurement equivalence must be checked before any newly selected source is used.
