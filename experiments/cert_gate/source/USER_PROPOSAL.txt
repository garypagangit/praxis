2. Thesis Statement, Research Question, Hypotheses
Thesis. The exchangeability caveat in Section 7 (G4) governs the claim language: the statistical bound is not asserted to survive adversarial distribution shift; the containment claim rests on the deterministic predicate layer.

Registered secondary outcomes (reported, not hypothesis-tested): risk-coverage curves over alpha in {0.005, 0.01, 0.02, 0.05}; per-alert inference cost and latency per arm; calibration-set-size versus bound-tightness curves; temporal drift degradation.

6. Gate Specification
The gate has two stacked components, applied in order. Suppression occurs only if both pass; every non-suppressed alert reaches the analyst queue unchanged. The gate never escalates, blocks, or modifies alerts; its only action is suppression, which makes its risk surface one-sided and auditable.

Component 1: deterministic eligibility predicates. An alert is suppression-eligible only if all registered predicates hold. Initial predicate set (finalized and frozen at the end of G0, before G1): (P1) the alert's referenced entities (host, user, rule ID, timestamps) verify against the underlying raw log record by exact match; (P2) the alert's rule class is on the registered eligible list (severity-capped: no critical-severity class is ever eligible); (P3) the alert is not part of a correlated multi-alert incident cluster at evaluation time; (P4) required fields are present and schema-valid. Predicates are pure functions of the alert and its source record; no model output participates in eligibility.

Component 2: conformal risk-control threshold. For eligible alerts, the scorer emits a benignness score. Split-conformal risk control on the calibration partition selects the suppression threshold such that the expected true-positive suppression rate is bounded by alpha with confidence delta. Calibration uses only calibration-partition labels; the procedure, including tie handling and the exact risk-control variant, is implemented once in a shared library and unit-tested against synthetic distributions with known ground truth before first use on real data.

Scorers (fixed set): (S1) a locally hosted Qwen-class LLM prompted for triage scoring, matching an evaluated model family from the Tier 1 literature where possible; (S2) Linear SVM on engineered alert features, chosen because the published SOC evaluation found lightweight classical models competitive with or superior to LLMs at binary triage; (S3) a score fusion of S1 and S2. No additional scorers may be added to hypothesis tests after registration.

7. Experiment Protocols
G0. Acquisition, license, and label audit (target: 1 week). Execute Section 4 acceptance checks on all tiers; generate Tier 3; produce the data quality memo (class counts per split, audit agreement, exclusions table, license records); freeze the predicate set and eligible rule-class list. G0 has no hypothesis; it is pass/fail per tier.

G1. Harness validity: reproduce published scorer baselines (target: 2 weeks). Run S1, S2, S3 ungated on Tier 1 and report TPR, FPR, F1 next to the published multi-model table. Success: reproduced metrics within the registered tolerance of the corresponding published values for the matched model family; the SVM arm establishes the classical reference. If reproduction fails tolerance, debug and document; no gate experiment starts until G1 passes or the deviation is logged with cause. G1 has no hypothesis; it calibrates the instrument.

G2. Gate calibration and guarantee validity, tests H1 (target: 3 weeks). For each (tier, scorer): 100 calibration/test resamplings from the non-test partitions; per resampling, calibrate the threshold at (alpha, delta) and record the realized TP-suppression rate on the resampling's held-out portion. Evaluate H1 per its decision rule; then run the single registered confirmation on the true test partition. Deliverables: violation-frequency table, realized-risk distributions, unit-test evidence for the calibration library.

G3. Workload reduction at certified risk, tests H2 (target: 3 weeks). On the test partition per (tier, scorer): suppression fraction of FP volume at alpha = 0.01, with 95% bootstrap CIs over seeds and resamples; conversion to alerts-per-analyst-day using alert-volume figures cited from the SOC workload literature (conversion factors recorded in the repo); full risk-coverage curves over the registered alpha grid. Comparison exhibit (reported, not tested): certified suppression alongside the published uncertified references (CORTEX FPR improvement; Tier 1 published FPR averages).

G4. Adversarial containment, tests H3 (target: 3 weeks). Corpus: Tier 3 plus a perturbed Tier 1 subset. Perturbations: prompt-injection payloads embedded in attacker-controllable alert text fields, replicating the published attack patterns against risk-based alerting thresholds; the payload set is fixed and committed before the first G4 run. Arms: (A) ungated LLM triage with automated suppression; (B) conformal threshold without predicates; (C) full gate. Measure TP miss rates per arm under clean and attacked conditions. Evaluate H3 per its decision rule. Claim-language constraint (registered): conformal guarantees assume exchangeability, which adversarial shift violates; the containment claim is attributed to the deterministic predicate layer (injected text can move a score but cannot forge exact-match evidence verification), not to survival of the statistical bound under attack.

G5. Calibration cost and drift (target: 2 weeks). Calibration-set-size ablation over the registered grid, reporting achievable bound tightness and suppression fraction per size. Temporal drift: where timestamps allow, calibrate on the earliest temporal block and evaluate on later blocks without recalibration; report guarantee degradation and derive a recalibration-cadence recommendation. Secondary outcomes only; no hypothesis test.

8. Statistical Analysis Plan
Primary analyses follow the decision rules in Section 2 verbatim. Uncertainty: bootstrap 95% CIs (10,000 resamples) on all fractions and deltas; seed-level variance reported for every stochastic arm; no point estimate is reported without dispersion. Multiplicity: H1-H3 are three registered confirmatory tests; secondary outcomes are exploratory and labeled as such. Exclusions: only those defined in Section 4, applied identically across arms. Negative and null results are reported in full; no configuration is dropped for underperformance.

9. Compute, Cost, and Latency Logging
From the first G1 run, every arm logs wall time, per-alert inference latency, peak memory, and (for LLM arms) token counts per alert. Per-alert cost is a registered secondary outcome because the deployment argument requires the cost leg of the trade-off to meet the same evidentiary standard as the detection leg.

10. Reproducibility Requirements
All configurations, split indices, seeds, ruleset hashes, payload sets, and this document are version-controlled in the experiment branch. Every reported number must be regenerable from a committed config plus a committed data snapshot or exact regeneration recipe. The calibration library ships with unit tests against synthetic known-truth distributions. Synthetic-data pipeline validation (the G-series equivalent of the APT-final 32-test suite) is completed and documented before G1 touches real data, and is reported as software verification, never as a detection result.
