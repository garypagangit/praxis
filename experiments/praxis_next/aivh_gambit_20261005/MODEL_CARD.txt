PX-117C research prototype, 5 October 2026
Question: autonomous AI versus human-operated command behavior.
Training sources: GAMBiT human exercise commands; Honey autonomous SSH agents.
Scope: ten simple discovery-like commands from a fixed executable allowlist.
No commands are executed. Timing, output and source IDs are not predictors.
Source and class remain confounded; this is not validated APT attribution.
Human partitions use conservative numeric participant groups across experiments.
Calibration selected lexical; main AI recall 1269/1300=97.62%, human errors4/61.
Mean human-group error8.95%; failed predeclared5%target. KYPOerrors5/180.
Verbs comparator: recall930/1300=71.54%; human errors0/61, KYPO0/180.
Zero observed false alerts is not a zero-risk guarantee; only9 human test groups.
All thresholds were fixed from calibration. No test-set retuning.
Install Python3.11 and requirements-lock.txt in a separate virtual environment.
Run: python predict.py --model lexical.joblib --commands example.json
Compare: python predict.py --model verbs.joblib --commands example.json
Example is constructed for CLI demonstration; not an experiment observation.
Only load trusted model files. AI score is not a calibrated attribution probability.
