Use existing 10-feature current-only and 18-feature current-plus-history LightGBM
classifiers, three seeds 8101/8102/8103. Retrain only the acquisition selector.
Use 50,000 label-independent randomly sampled development rows per seed from
forward out-of-fold records whose current classifier predicts benign. Sample
uniformly across eligible pooled rows, RNG 107000+seed. Explain each sampled row
using exactly its own forward-fold classifier. No full-data explanation on OOF rows.
History is the only optional evidence in this pilot; no DNS payload claim.

Target: realized history-warning utility on benign-predicted rows: +4 for exfil,
+1 for other attack, -1 for benign when the history classifier warns; otherwise 0.
This target prices a warning opportunity; it is not monetary or clinical utility.
Selectors: identical LightGBM regressors, 100 trees, 9 leaves, learning rate .05,
min_child_samples 30, reg_lambda 1, n_jobs 2, seed fixed, no tuning.
RAW uses current features plus all three current probabilities.
XAI uses RAW plus ten TreeSHAP contributions to the exfil-versus-benign raw margin.
SHUFFLED uses RAW plus the same contribution vectors permuted across training rows;
evaluation vectors are separately permuted without labels. SHAP_ONLY uses ten
contributions plus the three current probabilities. RAW_PADDED adds ten zeros to RAW
to diagnose dimensional padding effects. Same training rows, target and tree capacity.
Baselines: uncertainty (1 - benign probability), deterministic random, chronological.
No claims of comparison with full EDFA or AFA-SHAP; those remain required if promoted.

10, 50 and 200 cases per execution; report actual warnings and query counts separately.
