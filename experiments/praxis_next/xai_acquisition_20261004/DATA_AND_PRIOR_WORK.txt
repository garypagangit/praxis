PX-107 follow-up qualification, 2026-10-04

1. Existing AIT adapted flows
Available and previously verified locally. All eight executions have been used in
prior work, so none is untouched confirmation. The PX-107A pilot uses ten current
features and one optional eight-feature history bundle, not DNS content retrieval.
On both Wilson and Harrison, each of the three frozen current-only fits already
warns within the sole exfiltration episode proxy. Therefore the episode-recovery
endpoint is saturated before additional history is queried. Do not split this
episode into artificial independent attacks to claim additional episode recovery.

2. Korving DNS-tunnel collection
The inspected transfer completes, but its recorded rsync direction is a pull from
the tunnel server to the client. This does not qualify as outbound exfiltration.
The source contains 116 file-transfer archive configurations, not 116 verified
independent outward-theft episodes. Keep as possible tunneling stress data only.

3. CIC-Bell-DNS-EXF-2021 official source
https://www.unb.ca/cic/datasets/dns-exf-2021.html
Author documentation identifies outbound DNS transfers, a time schedule and raw
captures. The official download currently presents a registration form/server-error
message. No personal information submitted. Its benign traffic construction,
single-tool attack generation and limited runs need qualification for episode
generalization. No data acquisition was claimed from that endpoint.
The published detector already triggers stateful evidence using an uncertainty
threshold; implement this baseline before claiming a new acquisition capability.
Citation: Mahdavifar, S., Salem, A. H., Victor, P., Garzon, M., Razavi, A. H.,
Hellberg, N., & Lashkari, A. H. (2021). Lightweight hybrid detection of data
exfiltration using DNS based on machine learning. ICCNS 2021.

5. Public feature-only mirror
https://zenodo.org/records/18139853
Read the metadata and first CSV records only, without fitting. The mirror contains
a 46,770,313-byte file called CIC-Bell-DNS-EXF-2021.csv. Its header has lexical and
resource-record feature columns plus labels, but no timestamp, source host, capture
identity or transfer-episode identifier. This release does not qualify for our
episode recovery or timestamp-valid evidence-retrieval evaluation. Do not substitute
random row splitting for the missing execution identity.

Decision: run the bounded AIT development comparison to check implementation and
