# PX-103 — Explainable restoration of suppressed warnings under a case budget

Exploratory follow-up on already exposed UNRAVELED, AIT Wilson and Harrison. No first-on-APT claim: CyberShapley already addresses explanation and prioritization on coordinated APT data. Novelty of selective restoration remains unconfirmed. No paid compute or refitting.

Freeze this protocol, code and input hashes before computing results. Use the same three members and mean/OR outputs as PX-100. A candidate flow is OR-warning and mean-benign. Group by capture/source/destination/15-minute flow-completion bin. Group at bin close; do not peek beyond that time. Existing mean cases have already consumed baseline workload. Suppressed warnings in those cases are appended free of *additional case count*, not assumed free analyst effort. Rank remaining candidate cases with budgets 1, 5 and 20 additional cases per capture per 15-minute bin; no carryover. Baseline queue is not capacity constrained: these are supplemental budgets, not a model of total SOC capacity.

Compare mean only, unrestricted OR, confidence ranking, earliest candidate, ten seeded random rankings, and proposed source-coverage ranking. Confidence is maximum member attack-minus-benign class margin among suppressed flows in the case; it is not calibrated risk. Proposed ranking first favors a source with no baseline or selected warning in the preceding 60 minutes, then confidence. Recompute source novelty after each selection, to avoid spending simultaneous slots on the same source when an uncovered source is available. For the bin currently released, baseline warnings count as existing coverage. Do not use true attack labels, episode labels, test-derived severity or future observations for selection.

Predefined metrics: additional exfiltration episode proxies covered versus mean; benign-only supplemental cases; additional exfil warning flows; flow warning recall; first-warning time at bin close relative to earliest completed labeled exfil flow. Episode definitions: author-labeled exfil flows, same capture/source, consecutive start gap <=60 minutes; sensitivity 30 and120 minutes. Distinguish episode coverage from flow coverage. Report same fixed budgets and all outcomes. No significance claim from dependent flow rows or only three executions. Random baselines report distributions over ten fixed seeds, not uncertainty across attacks.

Primary hypothesis: source-coverage ranking covers more previously silent episode proxies than confidence ranking at the same supplemental budget without increasing benign-only supplemental cases. If coverage ties, no support for superiority. If the OR candidate pool cannot cover a missed episode, no ranking can recover it; report this ceiling.

Verification: source hashes, alignment to saved PX-093 OR/mean, budget checks, no base-warning removal, outputs subset of OR, deterministic explanation records for every selected case. Re-run selector with changed labels and confirm decisions are unchanged. Human usefulness, actual analyst time, causal attack explanation and new-campaign generalization are outside this experiment.
