# PX-105 — Does intervention replay add to an ordinary trace?

Bounded controlled diagnosis experiment. Real saved UNRAVELED expert scores are used with deliberately constructed routing failures; do not call these new naturally observed incidents. The underlying source is already exposed. No new fits, cloud calls or human reviews. Freeze code/input hashes before outcome analysis.

Select by ascending event hash up to 64 attack-labeled records per cause: (A) three-seed mean is benign while some member warns; (B) seed8103 current expert is benign but roles expert warns and selection chooses current; (C) same records as B, roles is requested but delayed to1.5 seconds beyond fixed1-second deadline; (D) both current and roles experts are benign. In B normal roles delay is0.25 seconds. D is unrecoverable only within the two experts examined. The evaluator retains cause labels; diagnosis functions receive no label. B/C pairs have identical model inputs, scores and final predictions, differing only in routing metadata. Do not invent a weak feature-attribution classifier: identical deterministic feature explanations of the same expert/input cannot distinguish this paired failure construction. That is an information limitation, not a measured SHAP benchmark.

Comparators: final-score-only reviewer abstains when a cause is not identifiable; ordinary complete-trace rules; intervention replay plus trace rules. Both trace methods have the same scores, routing and timing information. Ordinary trace predicts repair outcomes directly from these fields; replay executes the finite decision logic. Count exact cause matches and abstentions. Test three repair proposals per case: restore available warning (OR for aggregator; request roles for expert selector), extend deadline to2seconds (outside original contract), and no change. Score whether a proposal produces a warning within the original deadline contract. Returning a late warning after changing the contract is not a feasible repair. Independent evaluator computes outcomes with NumPy.

Primary criterion: replay must strictly improve diagnosis or feasible-repair prediction over ordinary complete traces to support incremental empirical value. A tie means no demonstrated advantage. Verify original final decisions are benign, actual attack labels only enter sampling/scoring, outcome keys are excluded from reviewer inputs, and B/C evidence identity. Incomplete trace controls remove timing; both methods should abstain for expert-routing cases. A truncated trace is not evidence that a complete trace method is inferior.

Limits: simple injected mechanisms, selected rows, small number of distinct mechanisms, no human usefulness, no new campaign, no measured workload or new detection performance. A successful engineering test cannot prove novelty. Literature must include general ML-pipeline debugging and provenance, not just IDS explanation papers. Record unavailable full texts explicitly.
