External validation review for the XAI comparison batch
4 October 2026

DECISION
External recorded-data validation is required before promoting any controlled
PX-110 finding to an APT detection claim. It must test the same stated outcome;
changing the endpoint because the external data have no misses is exploratory.
The available AIT data can support an external qualification now, but do not
provide episode-recovery headroom under the existing warning-preserving protocol.
No new public dataset is declared ready on the strength of its title alone.

WHAT "REAL" MEANS HERE
PX-110 consists of custom generated benign sequences and executed loopback file
transfers. AIT is independently recorded laboratory network activity: actual
testbed executions with simulated users and scripted attacks. Its publishers
explicitly call the released logs and netflows synthetic. It is external to our
generator, but it is not operational breach telemetry. AIT therefore tests some
generator-specific shortcuts, not real-world SOC effectiveness. Such a claim
would need operational data and its own labeling and privacy qualification.

HOW TO USE THE EXTERNAL STAGE WITHOUT CHANGING THE QUESTION
1. Report the qualification above for every batch arm; do not disguise it as
   unexecuted data collection or force six pointless model runs on a ceiling.
2. A controlled-data winner remains a candidate only. The current AIT result
   cannot confirm an episode-recovery improvement, however good its SHAP plots.
3. A new, fixed-budget prioritization experiment on AIT is possible, but it is
   a different operating point from preserving all current warnings. Freeze
   the budget and endpoint before fitting; label it exploratory on exposed data.
   Do not lower a budget after scoring simply to manufacture missed episodes.
4. Transport the method, not the PX-110 numeric thresholds or raw feature names.
   AIT current/history features differ from DNS message features. Fit only on
   development executions, freeze calibration, and prohibit test-label tuning.
5. Existing AIT contains only two evaluation episode proxies in this split, so
   it cannot meet a minimum of three missed episodes even if both were missed.
   A larger genuinely independent execution set is needed for that gate.
6. Do not rebrand flow-level gains, repeated windows, or seeds as recovery of
   separate attacks. Flow and case findings can remain secondary outcomes.

STOP AND INTERPRETATION RULE
Run the planned controlled batch once, retain every result, and promote only
methods beating matched non-XAI baselines with the declared workload. If none
improves, report the negative. If one improves, require eligible external data
before the thesis claims generalization. External replication is a condition of
the claim, not a promise already fulfilled by having a public dataset available.
