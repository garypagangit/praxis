SPLITS AND MODELS
Seed 11701. One deterministic 60/20/20 record-group split within each class.
No group enters fitting, calibration and test simultaneously. In addition,
hold out each agent family with the same reserved human test groups; remove
that family from fitting and calibration. Separately leave out each human
exercise, paired with the same reserved agent test groups. These are descriptive
transfer probes, not independent repeated tests or a held-environment study.
Cap fitting agents to four times fitting humans, sampled deterministically;
retain every eligible calibration/test record. Do not select hyperparameters.
Models: session-length logistic baseline, TF-IDF command/word n-gram logistic
classifier, and a small gradient-boosted model on content/sequence features.
Fit vectorizers and transformations only on fitting data. No timing features.
Run the three models concurrently with bounded one-thread numerical libraries.
