EXPLANATION CHECK
Exact additive contributions reconstruct all six linear scores (max error0).
This is established linear-model arithmetic, not a new XAI theorem.
Masking arguments in frozen word models flips4.70%(logistic) or4.26%(SVC) of
test labels, while top-five contribution overlap is only .223/.221. Apparent
prediction stability need not imply stable feature explanations. The transform
removes meaningful flags too, so it is not a semantics-preserving intervention.
Verb/masked models' invariance is a design property, not empirical discovery.

PRAXIS POSITION
Promising direction: test whether reduced command detail yields more reliable
attribution across matched environments. No first-passive-classifier claim:
TRACE https://arxiv.org/abs/2605.01186 already does passive model fingerprinting.
Honey accompanying study also reports behavioral fingerprints:
https://orbit.dtu.dk/en/publications/honey-for-the-agent-cyber-deception-and-behavioral-fingerprinting/
The candidate gap is binary transfer with a human-error limit and evidence
about feature dependence. Novelty and APT-wide efficacy remain unconfirmed.
