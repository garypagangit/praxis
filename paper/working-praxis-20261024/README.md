## Editing and reproduction

Edit the Word file directly, or edit `build_praxis.py` and regenerate with Python, python-docx and Pillow on Windows with Times New Roman installed. Keep `gmr.png` beside the builder: it is exported from the editable six-stage presentation diagram. The script is the authoring source; `manuscript_blocks.json` is an exported content inventory, not an automatically imported data source. `illustration_inputs.json` records invented confusion counts and derived example metrics, not study data. Future integration must replace these illustrations with validated predictions and grouped inference.
