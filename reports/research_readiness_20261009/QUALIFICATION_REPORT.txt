AI INVOLVEMENT IN SUSPICIOUS COMMAND SESSIONS
Data qualification completed October 9, 2026 (America/Los_Angeles)

DECISION
Proceed with measurement design and controlled data collection. Hold detector
training and operational performance claims: the inspected data do not provide
a qualified human / non-AI scripted automation / AI comparison. This decision
keeps the AI-involvement research direction. It does not revive the separate
missing-telemetry graph study.

SOURCE QUALIFICATION

TRACE [1]: Suitable methodological baseline: passive command TF-IDF/linear SVM
and held-out scaffold evaluation. Its published target is model-family identity
conditional on AI sessions. The paper says full data will be released later.
The artifact landing page and application scripts now return HTTP 200, but a
direct artifact API request returned HTTP 401 and no session corpus was
retrieved. Landing-page availability is not evidence of downloadable data.
Full dataset access and a human/scripted comparison remain unverified.

OHAI [2]: Suitable conceptual framework for observable indicators, uncertainty,
and human/AI/hybrid distinctions. The release supplies a report and case-based
discussion. No labeled session dataset was found in the inspected release.
Its heuristics do not supply calibrated operating thresholds for this study.

Lyptus [3,4]: Accessible paired-task human and AI source; data CC-BY-4.0. The
published participant rules prohibit AI assistance while allowing ordinary
tools and personal scripts. That supports a non-AI human-operator label under
the study protocol, not independent verification of compliance or a separate
scripted-only execution label. The native human terminal recorder and AI tool
recorder differ, despite sharing the .eval container format. Existing matched
records qualify for development and measurement audits only.

Honey [5]: Public release verified, with inputs.json and a 157,739,317-byte
Logs_final.zip, CC-BY-4.0. Its release MD5 matches the previous study's recorded
archive MD5. It contains controlled LLM shell sessions across five environments.
Useful as an AI-positive/environment-shift source; no matched human or scripted
negative arm is supplied by this release. No new download or model fit occurred.

Palisade CTF [6]: The inspected repository provides competition data. The sampled
Challenge Interactions CSV contains 34,982 rows with team_name, challenge_name,
interaction_type and created_at. Those are platform interaction events, not
shell command sequences. This inspected artifact cannot fill the command-level
negative-control gap. This is a bounded source review, not a claim that no other
public dataset exists.

WHY ANOTHER FEATURE SWEEP IS NOT JUSTIFIED
1. No separately labeled, comparable non-AI script-only sessions were found.
   Human use of a script is not proof of a fully scripted session. Replaying
   human or AI traces does not create independent scripted-origin evidence.
2. Native recording layer almost reveals the class directly. Keystroke absence,
   tool names, file structure, framework metadata, model tokens and collector
   timestamps cannot be attribution features. Timing requires one defined
   event boundary and consistent clocks in all arms.
3. The usable human sample is small and clustered. Even zero false flags in
   25 independent human sessions would yield a one-sided exact 95% binomial
   upper bound of 11.29% on false-positive probability: 1 - 0.05^(1/25).
   Repeated sessions from five experts make that independence assumption
   optimistic. There were no new detector predictions in this audit.
4. Previous model development and inspected results contaminate these records
   for confirmatory testing. A fresh split cannot undo prior inspection.
5. Command text alone cannot establish every form of historical AI assistance.
   A human can paste the same command as a model. The measurable first target
   should be runtime AI-directed action selection, with AI-assisted/hybrid
   execution explicitly separate and unknown cases allowed to remain unknown.

CONCRETE NEXT STEP
Use COLLECTION_PROTOCOL.txt to build a common-recorder pilot on isolated,
controlled tasks. Collect genuine no-AI human sessions, independently sourced
non-AI scripts, and labeled AI sessions under the same task/environment/recorder
conditions. First validate recording and label provenance; then freeze the
evaluation and collect unseen sessions. This audit did not recruit people,
launch attack sessions, call paid models, or fit another detector.
