## Difference From The Full Praxis Folder

The folder `reports/praxis_defense_ready_full_praxis_20260706/` contains committee-defense style praxis drafts with front matter, chapters, and appendices. Those are useful for a degree-defense package, but they read like structured outlines.

This folder contains paper-style manuscripts. The central addition is an explicit section in each manuscript named "Experimental Design Influences," which maps prior literature to the actual experiment design choices used in the repository.

## Recommended Use

Use these manuscripts when you need to explain:

- which research papers motivated the experiment,
- why the experiment was structured the way it was,
- what was measured,
- what the result proves,
- where the result is bounded,
- which repository artifacts support the claim.
