# Original calibration-answer archives

These two gzip files are byte-identical copies of the original CTIBench answer archives used to prepare this development experiment. Their original locations and SHA-256 hashes are preserved in [INPUT_AUDIT.json](../INPUT_AUDIT.json). They were copied here after scoring solely so the independent audit can run from a fresh Git checkout; no records or compressed bytes were changed.

The independent auditor checks each archive against the original recorded hash before reading its predictions. These archives contain original generator answers, not newly generated answers or additional evaluation questions.
