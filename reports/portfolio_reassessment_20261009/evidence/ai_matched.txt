PX120 / PX121 FIRST NEW-DATA EXPERIMENT REPORT
Gary Pagan Praxis - 7 October 2026

CONCLUSION
The first existing-public-data pilot does not support deployment or the claim
that we can reliably distinguish fully autonomous AI attacks from human APTs.
It does establish a reproducible test on a better task-aligned source and shows
why the earlier high accuracy is insufficient. Do not rewrite the Praxis as a
successful detector validation using these results.

PROBLEM AND HYPOTHESES
Problem: SOC analysts lack validated evidence for deciding whether observed
attack commands were generated by an autonomous AI operator or directed by a
human, particularly outside the detector's training source.
RQ1: Does the old command detector transfer to shared-task public human/AI data?
H1: >=80% AI recall with <=5% equal-expert human false-positive rate, conditional
on sufficient observable commands. PX120: not evaluable on matched ten-command
windows; coverage gate fails. No successful transfer conclusion.
RQ2: Do broader shell structure features separate operators when both human
experts and tasks are excluded from fitting/calibration overlap?
H2: The broader detector meets the same recall/FPR target. PX121: not met.
RQ3: Can agreement plus abstention reduce false attribution while preserving
useful detection and coverage? PX121: descriptive reduction, still inadequate.
RQ4 (future): Does attribution improve SOC triage decisions compared with the
same attack detection alerts without attribution? Not tested by these logs.
No analyst user study or actual analyst benefit is claimed.
These are pilot targets, not population guarantees or proof of fully autonomous
APT campaign attribution. A negative result is retained, not optimized away.

PX120: FROZEN OLD DETECTORS
Retained the original simple discovery-command allowlist and frozen thresholds.
Ten-command windows: only2 of47 human sessions and1 of222 AI sessions survive;
there are ZERO shared tasks with both classes. Thus the matched primary test is
not estimable. Five-command sensitivity leaves5 human and2 AI sessions, with
only ONE shared task. Scores on these tiny subsets are saved for transparency,
not evidence of generalization. This is a coverage failure, not a successful
external validation. No score tuning or replacement of the original study.

PX121: BROADER STRUCTURAL PILOT
Documented separately after coverage inspection, before new-model scoring.
Bashlex parses inert bash text into command verbs and shell-word argument counts;
redirects and embedded script text are not treated as arguments or executed.
First up to10 atomic commands, minimum3. Actual human echoed commands must also
occur literally in input recordings. Unsupported cursor edits are excluded.
This caught a terminal-overwrite artifact during pre-score inspection, but also
loses legitimate edited/tab-completed commands. Full terminal reconstruction is
not yet validated; extraction remains conservative and incomplete.

11 of47 human sessions survive, from5 experts.136 of222 AI sessions survive
before task matching (66 Anthropic,42 OpenAI,28 Google). Restricting to shared
eligible human tasks leaves11 human plus24 AI sessions on11 tasks.
AI python-tool calls are omitted:151 Anthropic,83 OpenAI,112 Google across the
initial222 sessions. Embedded python inside bash is represented only by its
shell invocation. Thus this is shell behavior, not a complete action trace.

Five outer folds each hold out one human expert AND all their tasks. The next
expert is calibration; its tasks are also excluded from fitting. Exact structural
fingerprints are excluded across partitions. Each training task has equal total
human and AI weight. C=1 logistic models; no hyperparameter or split search.
Threshold strictly above the maximum calibration-human score. Some calibration
folds have only ONE human session; this is a major instability, not a validated
low-FPR operating point. Raw counts must accompany all percentages.

Agreement requires both verb and combined detectors to flag AI. Disagreement
or any recorded parse failure causes abstention. Eight of35 eligible predictions
abstain; decision coverage27/35=77.1%. Denominators above include abstentions,
so they measure detection/false-flag burden over eligible sessions. They are NOT
conditional accuracy among decided sessions. Human-compatible is not proof of
human control. One shuffled-label run is only a sanity check, not a significance
test. No detector meets the registered recall/FPR pair. The small sample and
shared tasks/models preclude precise population error estimates.

SOC IMPLICATION
A hypothetical1%AI prevalence and the combined model's observed session rates
would yield roughly8 true AI flags and360 false human flags per1000sessions,
about2.3%precision. This is a scenario calculation, not an operational forecast;
the pilot rates are too uncertain and selected to estimate a real SOC population.
It illustrates why recall alone cannot establish SOC benefit.

NOVELTY AND CLAIM BOUNDARY
Agreement/abstention is a candidate baseline, not an established novel invention.
TRACE already studies terminal behavior attribution, and Honey studies agent
behavioral fingerprints; claiming novelty merely for command classification,
linear feature contributions or generic abstention is unsupported.
Candidate research contribution: validated evidence-quality gating plus task-
and-source-conditioned attribution, evaluated for transfer and false accusation.
That contribution needs a fuller prior-work comparison and stronger experiments.

NEXT EXPERIMENTS, USING EXISTING DATA ONLY
1. Reconstruct terminal input/output/timing jointly, with a blinded extraction
   audit, before refitting. Freeze a command-fidelity acceptance rule and report
   disagreements, missing tool actions and coverage by class/expert.
2. Qualify existing longer CyBench/CVEBench traces from the same release, checking
   matched task settings and available human identities before downloading more
   AI campaigns. Pool only under declared benchmark/participant holdouts.
3. Evaluate an evidence-quality/abstention candidate against verb/count baselines,
   then hold out AI model family AND environment, with fixed calibration.
4. Add public PWNJUTSU human red-team logs only if provenance and telemetry can
   support a comparable external false-flag challenge; do not label them proven
   unassisted-human or fully matched AI/human data.
5. Model SOC review load across explicit prevalences; actual analyst benefit and
   fully autonomous APT attribution remain separate unmeasured claims.
No new human recruitment or newly generated AI/human attack dataset is required
for these next qualification steps. Existing data may still be insufficient for
the user's strongest claim; a Praxis must state that limitation faithfully.
