RESULT
Measurement fidelity improved substantially. The existing command-only models
still fail the stated SOC attribution objective on harder external benchmarks.
This batch does not validate deployment, full AI-versus-human APT attribution,

Original PX120/PX121 experiments and the manuscript were preserved.

PX122 - COMMAND RECONSTRUCTION
Replay follows the actual terminal output and input in timing-event order using
pyte0.8.2 at recorded dimensions. Source bytes must align with timing lengths.
At an isolated Enter input event, capture the visible shell command; require a
subsequent shell editing-mode disable event to confirm submission. Support normal
and two-line Kali prompts, soft line wrapping, multiline paste, backspaces,
history recall and tab-completed names through actual echoed screen state.
These are recovered submissions/static shell syntax, not proof that every parsed
command node executed; pipelines/conditions/loops can have different execution.

90 existing human archive files:2partial files excluded,1empty sample excluded;
87session records processed.77recording triples aligned and replayed;12recordings
had a missing input or output stream. Four replay streams stop at a resize event;
only their pre-resize prefix is used. Batched/pasted Enter events that cannot be
assigned a reliable submission boundary remain excluded.
Recovered1,448 confirmed submissions.26 submissions fail shell parsing and are
retained in the audit, not silently turned into commands. Five unsupported terminal
events occurred across three sessions; recorded for follow-up, not certified as
harmless. Independent reconstruction validation remains pending.
15known-answer fixtures pass, covering completion/history, edits, multiline text,
wraps, Kali prompts, non-shell output, missing confirmation, batch/paste Enter,
resizes and truncated byte streams. Twelve deterministic real examples were
reviewed against raw input/output evidence with no discrepancy identified.
This is a developer audit, not a blinded independent accuracy estimate. A separate
review packet and answer key are supplied for independent adjudication.

Human coverage using >=3parsed shell command nodes:
InterCode:27/47sessions before AI task matching (previous parser11/47).
CyBench:7/8sessions,5tasks,3experts (04,05,08).
CVEBench:11/12sessions,10tasks,2experts (03,05).

Task control/submit/history/clear/exit commands are not classifier features.

The existing agreement rule considers parse failures across the whole session;

No baseline or candidate meets the recall/FPR pair. A larger model is not a
supported remedy for these measurement/calibration/generalization limitations.

WHAT THIS MEANS FOR THE PRAXIS
RQ1: Can commands distinguish operators across data sources/tasks? Current
baselines show substantial failure under the stronger transfer test.
RQ2: Does adding argument structure reliably help? Not supported in these pilots.
RQ3: Can abstention reduce false attribution while retaining useful coverage and
recall? False flags fall, but the current candidate loses too much coverage/recall.
RQ4: Does attribution help an SOC analyst? Still unmeasured. SOC_SCENARIOS.json
contains only declared-prevalence illustrations, not operational forecasts.

NEXT RESEARCH STEP
PX125draft specifies response-conditioned behavior: repeated actions after error,
changes in tool/action after error, and recurrence/stability across prefixes.
First qualify comparable response extraction: map human post-submission output
to commands and AI tool output to its tool-call ID; exclude grader/task-submit
feedback and model reasoning. A text error string is not automatically a verified
failed action. Pipeline errors must not be assigned to every command in a bundle.
Only after that measurement check should these features be tested against the
fixed baselines, with model-family/environment holdouts and explicit uncertainty.
Novelty remains unestablished; compare the actual method with TRACE/Honey and
related attribution work before making a new-contribution claim.
The two eligible CVE experts cannot support standalone expert-separated fit,
calibration and test. Three CyBench experts leave one expert per partition.
Pooled exploratory designs are possible, but more commands do not create more
independent humans. No new attack dataset or human recruitment is proposed.
