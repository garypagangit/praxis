## Project Description

This portfolio is a gated research program for building a defensible Praxis around APT detection, cyber threat intelligence, model extraction, and AI supply-chain robustness. The operating principle is fail-fast science: each idea must clear a data/access gate, a small pilot gate, and only then a formal preregistered multi-seed evaluation. Negative results are kept when they explain a bottleneck, because those bottlenecks tell us where the next Praxis should move.

The near-term center of gravity is deployment-realistic APT detection under shift. The strongest current candidate is `TTA for Streaming APT Detection`, because the local hybrid TTA gate and AWS rerun agree, the robustness audit passed all proceed gates, and the locked final replay preserves the large Macro-F1 and Reconnaissance recovery signal with a small override rate. The surrounding experiments test adjacent explanations: whether rare-stage imbalance can be fixed by weighting, whether stage-conditioned routing is actually useful, whether provenance-graph representations are interpretable, and whether CTI/LLM work can become a second Praxis line.

## Executive Read

The portfolio contains 17 formal plans in the DOCX index, while the local registry preserves 19 experiment ideas because it also includes two shelved/adjacent ideas. The work so far is not evenly distributed: there are real results for Praxis 04, a meaningful Phase A gate for Praxis 05, active infrastructure for large DARPA TC / OpTC mirrors, and active plans for SEC-LoRD / DS-LoRD plus AI supply-chain backdoor detection.

Current recommendation: make `TTA for Streaming APT Detection` the lead Praxis candidate and continue the rest as a gated queue. The hybrid TTA gate now has a strong local 3-seed positive result, an AWS rerun that matches within tolerance, a passed robustness audit, and a locked final replay with a matched confidence-reject baseline. Paper tables, figures, a full manuscript draft, and a defense checklist are now built. DAPT2020 provides appendix-level detector-recipe external-validity evidence, but the true DAPT TTA feasibility gate is negative. SEC-LoRD is no longer data-adapter blocked, but the cloud Llama prompt gate is negative for the current domain-seeding strategy. A stricter 2026-05-11 audit found the original parser was too generous on malformed outputs; after repair, domain seeding still makes both Llama models worse. The CTI graph line is cleaner too: ATT&CK is sufficient for simple TTP-set retrieval, GraphSAGE did not beat cheap baselines, few-shot attribution is only partially data-ready, and LLM threat-intelligence fusion is blocked on evaluation ground truth rather than data ingestion. Architecture work now adds a shared provenance window factory and detector-zoo registry, which helps reopen graph/drift/watermark/privacy experiments once labels are available. Consolidated final posture: `reports/EXPERIMENT_FINAL_EVALUATION_20260511.md`.
