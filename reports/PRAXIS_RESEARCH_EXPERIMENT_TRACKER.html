Research Program Concept

Praxis Research is a future-work-to-experiment program. We reviewed the 2025-2026 AI/ML paper set collected for this effort, focused on each paper's future-work openings, reproducibility surface, datasets, and method gaps, then converted the strongest opportunities into concrete Praxis experiment candidates.

The workflow is intentionally conservative: each candidate is deconflicted against work already completed, given a falsifiable gate, and then assigned a result state. Some ideas became full experiments with measured outcomes; some became source/data readiness gates; some were stopped because the evidence, data, simulator, labels, or compute path did not support a defensible claim. Negative and blocked outcomes are preserved because they explain what was tested and why it should not be overclaimed.

The tracker below is the GitHub-facing overview of that work. It shows the dashboard first, then links each experiment record to the supporting code, documents, results, and evidence inside this repository.

Experiment Repository Convention

Each PX-### row is treated as one experiment repository record. Where the experiment has runnable or reviewable artifacts, the tracker links to the relevant repository lane:

Lane Typical paths Meaning
Code scripts/, src/praxis/, cloud_jobs/, configs/ Executable scripts, runners, cloud handoffs, and frozen experiment configuration.
Documents reports/, paper/, README.md, EXPERIMENTS.md Protocols, dashboards, result syntheses, paper drafts, claim boundaries, and review notes.
Results runs/, report subfolders, generated JSON/CSV/HTML/PDF artifacts Measured outputs, audits, score tables, gate decisions, figures, and machine-readable summaries.
Evidence Linked primary reports inside each row The minimum support needed to defend the row's status. For source-gate or future items, this may be a source decision rather than a run result.

Ranking Rule

The source document's numeric composite score is preserved in the Idea Explorer table, but the priority order is not the same thing. This page ranks by current usefulness to the Praxis workstream: already-advanced positives first, then evidence artifacts, then cheap defensible start candidates, then ideas that should be merged, deferred, held, killed, or shelved.

Most important practical rule: do not restart broad experiment batches. Finish packaging the working positives, then source-gate only one new item at a time.
