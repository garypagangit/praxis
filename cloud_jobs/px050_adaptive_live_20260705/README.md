# PX-050 Live Model-Generated Adaptive Gate

This cloud job extends PX-050 beyond the fixed adaptive command fixture. It asks an open-weight code model to generate inert package-install command strings against a frozen deterministic tool-boundary gate, then scores whether the hardened gate blocks nonexistent-package and parser-stress variants while preserving clean valid-package utility.

No generated package-install command is executed. The job only captures strings, parses them, and writes reports.
